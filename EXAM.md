# ekz на экзамене

## Архитектурное решение (куда класть автоматизацию)

```
  Вы на экзамене
        │
        ▼
  ┌─────────────┐     ekz wizard / шаблон
  │ project.yaml│ ◄── столбцы, страницы, статусы
  └──────┬──────┘
         │ codegen
         ▼
  ┌──────────────────────────────────────┐
  │ SQLite + GORM models + migrations    │
  │ Go handlers / routes                 │
  │ Vite HTML + формы по полям           │
  └──────────────────────────────────────┘
```

**Автоматизация в `project.yaml`, не в «нарисуй любую ER-диаграмму».**

| Вопрос | Ответ |
|--------|--------|
| Генерировать ли таблицы из ваших столбцов? | **Да** — для **одной** бизнес-таблицы + `users` + `reviews` |
| Нужны ли 5–10 произвольных таблиц? | **Нет** — в билетах ДЭ 09.02.07 этого почти не бывает |
| Где «универсальность»? | Любая **тема** (еда, конференции, отель) через **одну схему** и разные поля |
| Что если билет другой? | `ekz` → «Свой билет с нуля» → вводите столбцы по имени |

## Сценарии запуска

### 1. Любой билет с нуля

```bash
ekz
```

Выберите **«Свой билет с нуля»**, затем сущность, столбцы, страницы.

### 2. Доставка еды (шаблон + правки)

```bash
ekz
# → Шаблон: доставка еды
# → папка: food-delivery
# → «Изменить столбцы?» — да/нет
```

Без вопросов:

```bash
ekz -name food-delivery -quick -preset food-delivery
```

### 3. Конференции.РФ

```bash
ekz -name conf -quick -preset conferences
```

### 4. Уже есть project.yaml

```bash
ekz
# → Продолжить из project.yaml

ekz -name copy -config project.yaml
```

## Поля для «доставка еды» (если с нуля)

| column | тип | подпись |
|--------|-----|---------|
| address | string | Адрес доставки |
| dish | enum | Блюдо |
| delivery_time | date | Время доставки |
| total | int | Сумма |

Статусы: `Новый` → `Готовится` → `Доставлен`. Отзывы: да. Страницы: все + слайдер.

## Запуск после генерации

```bash
cd food-delivery/backend && go mod tidy && go run .
cd ../frontend && npm install && npm run dev
```
