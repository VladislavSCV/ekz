# ekz — генератор решений ДЭ (09.02.07)

CLI-утилита для развёртывания готовых Fullstack-проектов демонстрационного экзамена.

## Сборка и запуск генератора

```bash
cd ekz
go mod tidy
go build -o ekz.exe .
```

Интерактивный режим:

```bash
./ekz.exe
```

Без диалога (удобно для скриптов и CI):

```bash
./ekz.exe -name my-conferences -preset conferences
```

Утилита запросит **имя проекта** и **пресет** (сейчас доступен «Конференции.РФ (Вариант №2)»), если флаги не указаны.

Проект создаётся в текущей директории, инициализируется `git`, в `frontend` добавляется `.npmrc` с зеркалом npmmirror.

## Структура репозитория

```
ekz/
  main.go                 # точка входа CLI
  internal/
    cli/                  # интерактивные вопросы
    generator/            # копирование и шаблонизация файлов
    presets/
      conferences/        # пресет «Конференции.РФ»
```

## Добавление новых пресетов

1. Создайте папку `internal/presets/<id>/` с шаблоном проекта.
2. Зарегистрируйте пресет в `internal/presets/presets.go` (`//go:embed` + запись в `registry`).
3. Файлы с переменными `{{.ProjectName}}` / `{{.ProjectSlug}}` сохраняйте с расширением `.tmpl`.

## Критерии приёмки (чеклист)

- [ ] `ekz` генерирует проект в **пустую** папку
- [ ] `npm install` во `frontend` проходит с `.npmrc`
- [ ] `go run .` в `backend` создаёт `data/app.db` без внешней СУБД
- [ ] Админ `Admin26` / `Demo20`, отзыв только после смены статуса
- [ ] UI корректен при 390×844 в DevTools
