# ekz

Универсальный генератор проектов для демонстрационного экзамена **09.02.07**.

Запускаете `ekz` — выбираете сценарий (с нуля, доставка еды, конференции, свой `project.yaml`) — при необходимости **поимённо задаёте столбцы БД и страницы** — получаете готовый Go + Vite проект.

## Установка

```bash
go install github.com/VladislavSCV/ekz@latest
```

## Режимы

| Команда | Описание |
|---------|----------|
| `ekz` | **Мастер** — сценарий, поля таблицы, страницы, статусы |
| `ekz presets` | Список встроенных шаблонов |
| `ekz -name X -config project.yaml` | Повторная генерация из конфига |
| `ekz -name food -quick -preset food-delivery` | Без вопросов, из шаблона |

## Как устроена «жёсткая универсальность»

| Уровень | Что делает ekz | Почему так |
|---------|----------------|------------|
| **project.yaml** | Единый источник правды: поля, страницы, статусы, бренд | Можно перегенерировать и править вручную |
| **Мастер** | Спрашивает столбцы **главной** таблицы по имени и типу | Вы описываете билет словами — ekz строит GORM, формы, API |
| **Шаблоны** | `food-delivery`, `conferences` — готовый YAML | Другая тема за 1 минуту: шаблон + «изменить столбцы» |
| **Не делаем** | Произвольные 10+ таблиц и ORM-конструктор | На ДЭ за 4 часа нужен **рабочий CRUD**, не админка БД |

Системные поля `id`, `user_id`, `created_at` и таблица `users` добавляются автоматически (требование ДЭ).

## Что спрашивает мастер

1. **Сценарий**: с нуля / шаблон / свой `project.yaml`
2. Имя папки и портала
3. Главная сущность: название, код, имя таблицы
4. **Поля (столбцы)** — имя в БД, подпись, тип (строка / число / дата / список)
5. Статусы, отзывы, страницы (чекбоксы)
6. Логин/пароль администратора, опционально цвета

## Пример: доставка еды

```bash
ekz
# → Шаблон: доставка еды → папка fooddelivery → при желании изменить столбцы
```

Или полностью свой билет: «Свой билет с нуля» и поля `address`, `dish`, `total`…
