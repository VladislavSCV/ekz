# ekz

Универсальный генератор проектов для демонстрационного экзамена **09.02.07** (Разработчик веб и мультимедийных приложений).

Вы описываете билет в **`project.yaml`** (или в интерактивном мастере) — ekz собирает готовый проект: **Go + Fiber + GORM + SQLite** и **Vite + HTML + JS + Bootstrap**.

Полная справка в терминале: **`ekz help`**

---

## Установка

```bash
go install github.com/VladislavSCV/ekz@v0.1.0
# или самая свежая:
go install github.com/VladislavSCV/ekz@main
```

Проверка: `ekz help`

> `go install ...@latest` может поставить старый **v0.0.1** без мастера полей. Используйте **@v0.1.0** или **@main**.

## Что генерируется

Папка проекта (например `myproject/`):

```
myproject/
├── project.yaml       ← описание билета (сохраняется автоматически)
├── README.md
├── backend/           ← API, SQLite, GORM
│   ├── main.go
│   └── internal/      ← models, handlers, auth, routes…
└── frontend/          ← страницы, стили, слайдер
    ├── index.html     ← вход
    ├── register.html  ← ФИО, телефон, email, логин, пароль
    ├── create.html    ← форма заявки (поля из YAML)
    ├── cabinet.html   ← кабинет, отзывы, слайдер
    └── admin.html     ← админка
```

**Таблицы БД:** `users` + одна бизнес-таблица (`bookings`, `food_orders`…) + опционально `reviews`.

Системные поля `id`, `user_id`, `created_at` добавляются автоматически.

## project.yaml — сердце генератора

Файл описывает **любой типовой билет** (не код). По нему строятся БД, формы и API.

| Блок | Что задаёт |
|------|------------|
| `portal` | Название и слоган сайта |
| `main.fields` | **Столбцы БД** и поля формы (имя, тип, подпись) |
| `main.statuses` | Статусы для админки |
| `pages` | Какие страницы создать (вход, регистрация, форма, кабинет, админ, слайдер) |
| `reviews` | Таблица отзывов (`true` / `false`) |
| `admin` | Логин и пароль администратора |
| `brand` | Цвета CSS |

### Как получить project.yaml

| Способ | Команда |
|--------|---------|
| После генерации | Файл в корне созданного проекта |
| Шаблон билета | `ekz schema export conferences` |
| Пустой пример | `ekz schema init` |
| Мастер без кода | `ekz` → «Только project.yaml — без генерации кода» |
| Мастер с кодом | `ekz` → ответы на вопросы → YAML в проекте |

Список шаблонов: `ekz presets`

### Как сделать свой билет

**Через YAML (рекомендуется для точной настройки):**

```bash
ekz schema export conferences   # или: ekz schema init
# правите project.yaml в редакторе
ekz -name my-de-2026 -config project.yaml
```

**Через мастер (стрелки ↑↓, Enter):**

```bash
ekz
# «Свой билет с нуля» → сущность, столбцы, страницы, статусы
```

**Быстро, без YAML:**

```bash
ekz -name conferences2026 -preset conferences
ekz -name food-delivery -preset food-delivery
```

Пересборка в **новую пустую папку** (старая не перезаписывается):

```bash
ekz -name myproject-v2 -config myproject/project.yaml
```

## Команды

| Команда | Описание |
|---------|----------|
| `ekz help` | Эта справка |
| `ekz` | Интерактивный мастер (↑↓, Enter) |
| `ekz presets` | Список шаблонов: `conferences`, `food-delivery` |
| `ekz schema init [файл]` | Пример `project.yaml` для правки |
| `ekz schema export <id> [файл]` | Выгрузить шаблон в YAML |
| `ekz schema help` | Справка по schema |
| `ekz -name X -config file.yaml` | Генерация из YAML |
| `ekz -name X -preset <id>` | Быстрая генерация без мастера |

Устаревшее: `ekz -quick -preset …` (флаг `-quick` опционален, достаточно `-name` + `-preset`).

## Мастер `ekz` (меню стрелками)

При запуске без флагов — пошаговые вопросы:

1. Сценарий: с нуля / доставка еды / конференции / из YAML / только YAML
2. Папка, портал
3. Сущность и **столбцы БД** (имя, тип, подпись)
4. Статусы, отзывы, **страницы** (мультивыбор)
5. Админ, цвета

Управление: **↑↓** — выбор, **Enter** — подтвердить, пробел — чекбоксы.

## Архитектура (почему не «любые 20 таблиц»)

На ДЭ почти всегда: **users + одна заявка/заказ + отзывы**. Так генератор остаётся надёжным за 4 часа. Универсальность — через **разные поля и темы** в `project.yaml`, а не через ORM-конструктор.
